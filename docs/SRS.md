# Software Requirements Specification (SRS) — PulseFit AI

**Project Name:** PulseFit AI  
**Author:** Nachiket Gadilohar  

---

## 1. Functional Requirements
- **FR-BIO-01**: System MUST compute Recovery Index (0-100) using weighted HRV, sleep quality, and previous day volume.
- **FR-AGENT-01**: System MUST generate structured JSON workout plans via LLM agents.
- **FR-DSH-01**: Streamlit/React dashboard MUST render interactive charts for workout consistency and volume load.
